## Updating the site
This is a single self-contained `index.html` — no build step. Edit it directly (or ask Claude to), then commit and push; GitHub Pages redeploys automatically within a minute or two.

## Setup
All URLs already point to `mrsazreen1-spec.github.io/homeostasis-hub/`. If you ever rename the repo or move to a custom domain, update the canonical/OG URLs in `index.html`'s `<head>`, plus `robots.txt` and `sitemap.xml`, to match.
